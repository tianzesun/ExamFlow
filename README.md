# ExamFlow
A lightweight exam seating and printing companion for Crowdmark.
ExamFlow = Exam PDF + Student Roster + Seating Assignment → Printable Exam Package

1. Import Crowdmark exam PDF
2. Import student roster
3. Define rooms and seats
4. Assign students to seats
5. Generate personalized exam PDFs
6. Generate seating maps
7. Generate signature sheets
8. Export/print exam package
