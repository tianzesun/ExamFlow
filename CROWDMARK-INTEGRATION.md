# Crowdmark Integration Guide

## Current Integration

ExamFlow integrates with Crowdmark through file-based export/import.

### Supported Workflow

```
Crowdmark
    ↓
Export Exam Template (PDF)
    ↓
Manual download to local machine
    ↓
Upload to ExamFlow
    ↓
ExamFlow validates and stores template
    ↓
ExamFlow generates personalized exams using template
```

### What Crowdmark Exports

When exporting from Crowdmark, the following is available:
- PDF template with exam content
- Crowdmark exam ID (metadata)
- Crowdmark URL (metadata)
- Original page layout and formatting

### What ExamFlow Does With Templates

1. **Validates** PDF structure (header, readability)
2. **Stores** original template immutably
3. **Overlays** student information (name, ID, room, seat) on first page
4. **Preserves** original exam content, page order, and Crowdmark QR codes
5. **Generates** personalized PDFs for each student

### What ExamFlow Does NOT Modify

- Original exam content
- Crowdmark QR codes
- Crowdmark booklet identifiers
- Page ordering
- Assessment structure

## Crowdmark API (Future)

### Current Status

Crowdmark API access is **NOT IMPLEMENTED** in ExamFlow.

### Potential Future Integration

If institutional Crowdmark API access is obtained:

```
ExamFlow
    ↓
Crowdmark API
    ↓
Automatic exam import
Automatic roster sync
Booklet identifier retrieval
Submission linking
```

### Potential API Capabilities

| Capability | Status | Notes |
|------------|--------|-------|
| Import assessments | NOT IMPLEMENTED | Requires API access |
| Import rosters | NOT IMPLEMENTED | Requires API access |
| Retrieve booklet info | NOT IMPLEMENTED | Requires API access |
| Link submissions | NOT IMPLEMENTED | Requires API access |
| Sync grades | NOT IMPLEMENTED | Out of scope |

### Integration Boundary

If Crowdmark API is implemented, it should be isolated in:

```
backend/
└── integrations/
    └── crowdmark/
        ├── __init__.py
        ├── client.py
        ├── models.py
        └── sync.py
```

No Crowdmark-specific code should exist outside this module.

## QR Code Integration

### Current State

- ExamFlow generates its own QR codes for document verification
- Crowdmark QR codes on the original template are preserved during PDF overlay
- ExamFlow QR tokens verify document authenticity within ExamFlow

### Crowdmark QR vs ExamFlow QR

| Feature | Crowdmark QR | ExamFlow QR |
|---------|-------------|-------------|
| Purpose | Student/exam matching | Document verification |
| Generated by | Crowdmark | ExamFlow |
| Scanned by | Crowdmark scanners | ExamFlow verify endpoint |
| Located on | Original template | Added to personalized PDF |

### QR Verification

ExamFlow provides `GET /api/verify/{token}` for QR verification:
- Returns document validity status
- Logs verification attempts
- Does not require authentication (designed for proctor use)

## Export from Crowdmark

### Recommended Export Settings

When exporting from Crowdmark for ExamFlow:
1. Export as PDF (not other formats)
2. Include all pages
3. Do not modify page order
4. Preserve original formatting

### Template Quality Requirements

- PDF must be valid and readable
- Pages should be standard letter/A4 size
- Content should not extend into header area (ExamFlow overlays student info there)
- Crowdmark QR code should be in a consistent location

## Limitations

1. **Manual process**: Export from Crowdmark, upload to ExamFlow (no automation)
2. **No API access**: Cannot programmatically retrieve exams or rosters from Crowdmark
3. **No bidirectional sync**: Changes in Crowdmark are not reflected in ExamFlow
4. **No submission linking**: ExamFlow cannot link to Crowdmark submissions
5. **No grade integration**: ExamFlow does not handle grading

## Recommendations

1. Document the Crowdmark export process for administrators
2. Create a step-by-step guide for template upload
3. Test template compatibility with actual Crowdmark exports
4. Monitor Crowdmark API availability for future integration
5. Maintain clear separation between ExamFlow and Crowdmark responsibilities
